# Atria Renewable

Smart Solar Solutions for Andhra Pradesh. Rooftop solar solutions for homes and businesses across Andhra Pradesh.

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
